# sql-query-project
Academic SQL project demonstrating database queries, joins, filtering, and reporting.
## Included SQL Files

* `01-northwind-query-fundamentals.sql` — Demonstrates foundational SQL querying through SELECT statements, filtering, sorting, pattern matching, date conditions, null handling, distinct results, calculated text fields, and result limiting. *(Assignment 2)*

* `02-northwind-multitable-joins.sql` — Demonstrates explicit and implicit joins, outer joins, multi-table queries, aliases, UNION operations, employee and customer relationships, and date-based order filtering. *(Assignment 3)*

* `03-northwind-aggregate-analysis.sql` — Uses aggregate functions, GROUP BY, HAVING, calculated order totals, discount calculations, freight analysis, recent-order dates, and multi-table summaries to analyze Northwind business data. *(Assignment 4)*

* `04-northwind-subquery-analysis.sql` — Demonstrates subqueries used to compare inventory against averages, identify customers without orders, filter customers by country, examine employee reporting relationships, and analyze late shipments. *(Assignment 5)*

* `05-retail-order-schema-and-indexes.sql` — Creates a relational order-management database with customer, ZIP code, order, product, and ordered-product tables. Demonstrates data types, primary and foreign keys, composite keys, ALTER TABLE constraints, and database indexes. *(Assignment 6)*

* `06-advanced-queries-and-college-schema.sql` — Combines advanced Northwind queries, subqueries, joins, null-value analysis, calculated employee compensation, and ranked product results with the creation of a separate college enrollment database using primary keys, foreign keys, and relational tables. *(Final Exam)*

* `setup/northwind-database-setup.sql` — Initializes the Northwind sample database used by the query assignments. This supporting file is included only to provide the database structure required to run the examples.
